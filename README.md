# 桌面性能助手 · Desktop Performance Monitor

一个常驻 Windows 桌面的性能监控面板：把处理器、显卡、内存、磁盘分区、物理磁盘和剪贴板的状态，收进一块半透明的小面板里（360 × 540），不打断正在做的事。

界面采用液态玻璃（Liquid Glass）材质，面板本体与每一张子项卡片都是自绘的实时渲染。

应用图标同样是按这套语言画的——深色玻璃底 + 仪表环 + 环尾的白色光点：

## 功能

### 实时监控卡（处理器 / 显卡 / 内存）

三张彼此独立的卡片，共用同一套电路式视觉语言：

| 卡片 | 显示内容 |
| --- | --- |
| 处理器 | 温度、利用率圆环（环内为真实利用率整数） |
| 显卡 | 温度、已用显存、利用率圆环 |
| 内存 | 温度、已用内存、随负载变色的呼吸灯 |

- **利用率圆环**：环内显示整数百分比，圆环描边与占比弧按负载着色——≤55% 为绿，>55% 为红，与处理器卡的判定一致。
- **白色光点**：沿卡片边框匀速巡回一圈，直观表达「这张卡是活的」。
- **呼吸灯**：负载越高越亮，磁盘读写中、内存吃紧时会整块转为红色。
- **单位状态灯**：容量单位在 GB / MB 之间切换时，右侧（GB）/ 左侧（MB）的状态灯同步点亮当前生效的那一个。

### 磁盘分区

每个分区一条，容量占用条按占用率分档着色（正常青、75% 以上橙、90% 以上红），并显示占用率与温度。

- 正在读写的分区：白色光点沿该分区卡片边框巡回，盘符文字下方出现呼吸灯；停止读写后光点自动淡出。
- 读写是**按卷**统计的（C 盘动不会点亮同一块物理盘上的 E 盘）。

### 物理磁盘活动

每块物理磁盘一张卡片，显示读取速度、写入速度、占用率与温度。

### 剪贴板

手动点击「检测」扫描最近 4 条剪贴板记录，可单条一键复制。

### 整机操作

底部四个按钮：**此电脑**（打开资源管理器）、**刷新**（立即重新采集）、**设置**、**电源**（关机 / 重启，带二次确认）。

### 常驻与省心

- **托盘常驻**：可隐藏到托盘，双击托盘图标恢复；托盘菜单提供「显示面板 / 隐藏到托盘 / 退出」。
- **置顶 / 贴桌面底层**：面板可设为始终置顶，也可贴着桌面底层不打断游戏与全屏。
- **开机自启**：可开启开机自启动（支持快速启动场景）。
- **分模块开关**：实时监控卡、分区、磁盘卡、剪贴板、底部按钮都能单独隐藏，只留你要的那几块。
- **低功耗模式**：保留必要刷新，降低后台占用。

## 界面材质

面板本体是自绘的液态玻璃，七层结构（自下而上）：

| 层 | 作用 |
| --- | --- |
| L1 基底 | 清透蓝调对角渐变，决定面板「透不透」 |
| L2 中央暗区 | 径向暗化，制造凹面纵深 |
| L3 三点反射 | 左上暖球 + 右下冷板 + 上缘白灯条，给出方向感 |
| L4 噪声 + 磨砂 | 极低不透明度颗粒与薄雾，破除塑料感 |
| L5 折射棱边 | 1px 外缘渐变高光 + 内缘斜面 + 红蓝色差双描边 |
| L6 子项卡片 | 4~6% 白半透明面 + 1px 渐变边缘光 |
| L7 内容 | 文字与图形 |

子项卡片是半透明的，因此金属底层的反射会自然透上来——这是刻意的层次感，不是渲染缺陷。

## 系统要求

- Windows 10 / 11，**64 位**（x64）
- .NET Framework 4.8（系统自带；若缺失，安装程序会在安装完成后提示从微软官网下载安装，下载失败不影响程序本身）

## 安装

从 [Releases](../../releases) 下载 `DesktopPerformanceMonitor_Setup_1.0.1.exe`，双击运行。

- 用户级安装，**不需要管理员权限、不弹 UAC**
- 默认安装目录：`%LOCALAPPDATA%\Programs\桌面性能助手`
- 安装后生成开始菜单项、可选的桌面快捷方式，以及「设置 → 应用」里的卸载入口
- 卸载不会删除你的配置（配置留在 `%LOCALAPPDATA%\PerfMonitorWPF\`）

> 安装包未做代码签名，部分系统首次运行会提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## 从源码编译

需要：Windows SDK / Visual Studio 的 MSBuild、.NET Framework 4.8 目标包。

```bat
:: 直接运行仓库根目录的脚本（自动编译 Release 并整理输出）
一键编译.cmd

:: 或者手动调用 MSBuild
MSBuild.exe Project\PerfMonitorWPF.csproj /p:Configuration=Release
```

第三方依赖已随仓库内置在 `Project\packages\`，克隆后即可直接编译，无需额外下载。

## 数据与隐私

- 所有指标**只在本机读取**，不上传、不联网、没有遥测或统计。
- 配置与日志写在 `%LOCALAPPDATA%\PerfMonitorWPF\`，卸载程序不会清除。
- 剪贴板内容**仅在你点击「检测」时**读取，只显示在面板上，不写盘、不外发。
- 面板不会读取除硬件传感器、磁盘卷、剪贴板之外的任何用户数据。
